# DECODER_4X16 using Verilog HDL

## Project Overview
This project implements a DECODER_4X16 using Verilog HDL.
The design includes Behavioral, Dataflow, and Structural modeling along with a Testbench for simulation and verification.

## Features
- Behavioral Modeling
- Dataflow Modeling
- Structural Modeling
- Testbench for Functional Verification

## Files
- decoder4x16.v
- decoder4x16_tb.v

## Software Used
- Xilinx Vivado

## Language
- Verilog HDL
