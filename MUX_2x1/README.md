# MUX_2x1 using Verilog HDL

## Project Overview
This project implements a MUX_2x1 using Verilog HDL.
The design includes Behavioral, Dataflow, and Structural modeling along with a Testbench for simulation and verification.

## Features
- Behavioral Modeling
- Dataflow Modeling
- Structural Modeling
- Testbench for Functional Verification

## Files
- mux2x1.v
- mux2x1_tb.v

## Software Used
- Xilinx Vivado

## Language
- Verilog HDL
