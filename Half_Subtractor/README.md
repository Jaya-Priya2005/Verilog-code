# Half subtractor using Verilog HDL

## Project Overview
This project implements a Half subtractor using Verilog HDL.
The design includes Behavioral, Dataflow, and Structural modeling along with a Testbench for simulation and verification.

## Features
- Behavioral Modeling
- Dataflow Modeling
- Structural Modeling
- Testbench for Functional Verification

## Files
- half_sub.v
- half_sub_tb.v

## Software Used
- Xilinx Vivado

## Language
- Verilog HDL
