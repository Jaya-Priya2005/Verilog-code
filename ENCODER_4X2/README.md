# ENCODER_4X2 using Verilog HDL

## Project Overview
This project implements a ENCODER_4X2 using Verilog HDL.
The design includes Behavioral, Dataflow, and Structural modeling along with a Testbench for simulation and verification.


## Features
- Behavioral Modeling
- Dataflow Modeling
- Structural Modeling
- Testbench for Functional Verification

## Files
- Encoder_4x2.v
- Encoder_4x2_tb.v

## Software Used
- Xilinx Vivado

## Language
- Verilog HDL
