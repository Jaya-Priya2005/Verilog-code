# DECODER_2X4 using Verilog HDL

## Project Overview
This project implements a DECODER_2X4  using Verilog HDL.
The design includes Behavioral, Dataflow, and Structural modeling along with a Testbench for simulation and verification.

## Features
- Behavioral Modeling
- Dataflow Modeling
- Structural Modeling
- Testbench for Functional Verification

## Files
- decoder2x4.v
- decoder2x4_tb.v

## Software Used
- Xilinx Vivado

## Language
- Verilog HDL
