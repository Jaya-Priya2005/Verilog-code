# DECODER_3X8 using Verilog HDL

## Project Overview
This project implements a DECODER_3X8 using Verilog HDL. 
The design includes Behavioral, Dataflow, and Structural modeling along with a Testbench for simulation and verification.

## Features
- Behavioral Modeling
- Dataflow Modeling
- Structural Modeling
- Testbench for Functional Verification

## Files
- decoder3x8.v
- decoder3x8_tb.v

## Software Used
- Xilinx Vivado

## Language
- Verilog HDL
