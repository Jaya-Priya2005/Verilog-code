# MUX_8X1 using Verilog HDL

## Project Overview
This project implements a MUX_8X1 using Verilog HDL. 
The design includes Behavioral, Dataflow, and Structural modeling along with a Testbench for simulation and verification.

## Features
- Behavioral Modeling
- Dataflow Modeling
- Structural Modeling
- Testbench for Functional Verification

## Files
- mux8x1.v
- mux8x1_tb.v

## Software Used
- Xilinx Vivado

## Language
- Verilog HDL
