# ENCODER_16X4 using Verilog HDL

## Project Overview
This project implements a ENCODER_16X4 using Verilog HDL.
The design includes Behavioral, Dataflow, and Structural modeling along with a Testbench for simulation and verification.

## Features
- Behavioral Modeling
- Dataflow Modeling
- Structural Modeling
- Testbench for Functional Verification

## Files
- encoder16x4.v
- encoder16x4_tb.v

## Software Used
- Xilinx Vivado

## Language
- Verilog HDL
