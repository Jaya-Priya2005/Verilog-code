# Full Subtractor using Verilog HDL

## Project Overview
This project implements a Full Subtractor using Verilog HDL. 
The design includes Behavioral, Dataflow, and Structural modeling along with a Test bench for simulation and verification.

## Features
- Behavioral Modeling
- Dataflow Modeling
- Structural Modeling
- Test bench for Functional Verification

## Files
- full_sub.v
- full_sub_tb.v

## Software Used
- Xilinx Vivado

## Language
- Verilog HDL
