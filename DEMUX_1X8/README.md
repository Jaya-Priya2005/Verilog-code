# DEMUX_1x8 using Verilog HDL

## Project Overview
This project implements a DEMUX_1X8 using Verilog HDL. 
The design includes Behavioral, Dataflow, and Structural modeling along with a Testbench for simulation and verification.

## Features
- Behavioral Modeling
- Dataflow Modeling
- Structural Modeling
- Testbench for Functional Verification

## Files
- demux1x8.v
- demux1x8_tb.v

## Software Used
- Xilinx Vivado

## Language
- Verilog HDL
